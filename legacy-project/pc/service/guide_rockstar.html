다이렉트 게임즈 구매방법

  1. 상품 선택

    다이렉트 게임즈에서 원하는 상품을 선택하여 상세 페이지로 이동합니다.

  2. 주문하기

    구매하고자 하는 게임을 선택하신 후 `구매하기`를 클릭합니다.

  3. 결제하기

    `구매하기`를 클릭하여 안내에 따라 결제를 완료합니다.

  4. 주문완료

    게임 구매가 완료되었습니다! 구매하신 제품 코드(키)는 `마이페이지 > 주문완료 내역`에서 확인 가능합니다.

락스타 게임즈(Rockstar Games) 가입 및 계정 만들기

  1. 가입 및 로그인

    Rockstar Games Social Club(https://socialclub.rockstargames.com/) 접속 후 메인 페이지 중앙의 ‘로그인’을 선택합니다. 이미 가입하신 고객님은 페이지가 전환된 후 계정정보를 입력하여 로그인이 가능합니다. 계정 생성을 원하는 고객님께서는 ‘회원 가입’을 선택하시길 바랍니다.

  2. 생년월일 입력

    화면이 바뀌며 생년월일을 입력하는 창이 표시됩니다. 가입을 원하는 고객님의 생년월일을 입력하신 후 ‘다음’을 선택합니다.

  3. 락스타 게임즈 약관 및 정책

    Rockstar Games 약관 및 정책의 내용을 확인하고 체크박스를 클릭하여 동의하신 후 ‘다음’을 선택합니다.

  4. 계정 정보 입력

    Rockstar Games 가입 양식에 맞게 차례대로 입력하시길 바랍니다. 특히 이메일 주소는 추후 비밀번호 분실 시 재발급을 위해 반드시 필요한 정보에 해당되므로 자주 사용하시는 이메일 주소를 입력하는 것을 권장합니다. 마케팅 메일의 수신 희망 여부를 결정하신 후 ‘다음’을 선택합니다.

  5. 이메일 주소 인증

    “4. 계정 정보 입력”에서 고객님께서 입력하신 이메일 주소에 Rockstar Games Social Club으로부터 화면과 같은 이메일이 도착하였는지 확인을 바랍니다. 메일 내용을 확인한 후 ‘이메일 주소 인증하기’를 선택합니다.

  6. 락스타 게임즈 각종 설정 선택

    Rockstar Games 및 Rockstar Games Social Club의 각종 설정을 편집할 수 있습니다. 편집을 마친 고객님께서는 ‘계속’을 선택합니다.

  7. 계정 생성 완료

    Rockstar Games Social Club의 페이지로 전환됩니다. 계정 생성이 정상적으로 완료되면 좌측 상단에 고객님의 Rockstar Games Social Club ID가 표시됩니다. 이로서 Rockstar Games Launcher 계정 생성은 끝이 납니다.

락스타 게임즈 런처(Rockstar Games Launcher) 설치

  1. 락스타 게임즈 소셜 클럽 메인 페이지

    Rockstar Games Social Club(https://socialclub.rockstargames.com/) 접속 후 메인 페이지 우측 상단의 ‘LAUNCHER 다운로드’를 선택합니다.

  2. 락스타 게임즈 런처 다운로드

    화면이 바뀌면 좌측 하단에 보이는 ‘Windows용 다운로드’를 선택합니다. 이후 자동으로 Rockstar Games Launcher의 설치 파일 다운로드가 진행됩니다.

  3. 락스타 게임즈 런처 설치 완료

    설치가 정상적으로 완료 되면 자동적으로 클라이언트가 실행되며 아래와 같은 화면이 표시됩니다. 이것으로 Rockstar Games Launcher 설치는 끝이 납니다.

락스타 게임즈 게임 등록 및 플레이

  1. Rockstar Games Launcher 메인 페이지

    락스타 게임즈 런처 실행 및 로그인 후 화면 우측 상단의 ‘Rockstar Games Launcher 메인 페이지’ 아이콘을 선택합니다. 이후 슬라이드 형식으로 표시되는 페이지에서 ‘코드 등록’을 선택합니다.

  2. Rockstar Games 활성화 코드 입력

    Rockstar 활성화 코드 화면으로 페이지가 전환됩니다. 다이렉트 게임즈를 통해 고객님께서 구매하신 락스타 게임즈 활성화 코드를 입력하신 후 ‘확인’을 선택합니다.

  3. Rockstar Games Social Club 이용 규약

    Rockstar Games Social Club 이용 규약이 안내됩니다. 고객님께서 등록한 제품은 현재 계정에 영구히 귀속되며, 양도할 수 없음을 인지하셨다면 체크박스를 클릭한 후 ‘사용’을 선택합니다.

  4. Rockstar Games 게임 등록 완료

    페이지가 바뀌며 ‘다음 콘텐츠가 활성화되었습니다!’라는 문장이 표시됩니다. 이로서 고객님이 구매하신 락스타 게임즈 제품 등록이 정상적으로 완료 되었습니다.

  5. 락스타 게임즈 런처 메인 페이지

    제품 구매 후 고객님의 PC에 해당 게임을 설치하는 과정을 거쳐야 합니다. Rockstar Games Launcher 메인 페이지에 화면과 같이 ‘지금 설치’ 버튼이 표시됩니다.

  6. 설치 완료 및 게임 플레이

    게임 설치가 정상적으로 완료되면 화면과 같이 ‘플레이’ 버튼이 표시됩니다. 이것으로 고객님이 구매하신 락스타 게임즈 게임을 언제든지 플레이 가능합니다.
