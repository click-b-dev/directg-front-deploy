라이브러리 게임 등록 및 플레이

  • 에픽 게임즈 클라이언트 메인 페이지

    에픽 게임즈 클라이언트를 실행해주시기 바랍니다. 로그인 후 화면 우측 상단의 ‘라이브러리 게임 등록 및 플레이’ 아이콘을 선택합니다. 이후 슬라이드 형식으로 표시되는 페이지에서 ‘코드 사용’을 선택합니다.

  • 에픽 게임즈 제품 코드 입력

    제품 등록 화면으로 페이지가 전환됩니다. 다이렉트 게임즈를 통해 고객님이 구매하신 에픽 게임즈 제품의 코드를 입력합니다.

  • 에픽 게임즈 제품 코드 사용

    정상적으로 코드 입력을 완료하면 고객님이 구매하신 제품의 썸네일이 좌측에 표시됩니다. 이후 파란색 버튼의 ‘사용’을 선택합니다.

  • 에픽 게임즈 제품 등록 완료

    ‘제품을 성공적으로 등록했습니다!’라는 문장이 표시됩니다. 이로서 고객님이 구매하신 에픽 게임즈 제품의 등록이 정상적으로 완료 되었습니다.

  • 에픽 게임즈 클라이언트 메인 화면

    에픽 게임즈 클라이언트 메인 페이지의 좌측 메뉴에서 ‘라이브러리’를 선택합니다. 고객님의 PC에 해당 게임을 설치하는 과정을 거쳐야 합니다. 구매하신 게임을 마우스로 클릭하시기 바랍니다.

  • 에픽 게임즈 최종 사용자 라이선스 계약

    최종 사용자 라이선스 계약 내용이 표시됩니다. 내용을 확인하고 체크 박스를 클릭하여 동의한 후 ‘수락’을 선택하면 구매하신 게임의 다운로드 및 설치가 진행됩니다.

  • 설치 완료 및 게임 플레이

    게임 설치가 정상적으로 완료되면, 라이브러리에서 구매하신 에픽 게임즈 게임을 언제든지 플레이할 수 있습니다.
    (※ 구매하신 게임 플레이에 성인 인증이 필요한 경우, 등록 불가 상황 대처법 페이지를 확인해 주시기 바랍니다.)
