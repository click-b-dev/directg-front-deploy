가입 및 계정만들기

  • 상품 선택

    다이렉트 게임즈에서 원하는 상품을 선택하여 상세 페이지로 이동합니다.

  • 주문하기

    구매하고자 하는 게임을 선택하신 후 `구매하기`를 클릭합니다.

  • 결제하기

    `구매하기`를 클릭하여 안내에 따라 결제를 완료합니다.

  • 주문완료

    각각의 체크 박스를 클릭한 후 ‘동의합니다’를 선택합니다. 이전 상태의 ⑦팝업창으로 돌아오게 되며, 정보 수신을 원하는 고객님께서는 체크 박스를 클릭한 후에 ‘계속’을 선택합니다. 정보 수신을 원하지 않는 고객님께서는 체크 박스 클릭 없이 ‘계속’을 선택합니다.

  • 인증용 보안 코드 입력

    게임 구매가 완료되었습니다! 구매하신 제품 코드(키)는 `마이페이지 > 주문완료 내역`에서 확인 가능합니다.

  • 계정 생성 완료

    ⑩팝업창에 인증용 보안 코드를 입력하신 후 ‘이메일 인증’을 선택합니다. 이후 에픽 게임즈 메인 페이지로 화면이 자동 전환되며 이를 통해 에픽 게임즈 계정 생성은 끝이 납니다.
