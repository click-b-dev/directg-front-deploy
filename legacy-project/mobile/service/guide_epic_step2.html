가입 및 계정만들기

  • 가입 및 로그인

    에픽 게임즈(https://www.epicgames.com/store/ko/) 접속 후 메인 페이지 우측 상단의 ‘로그인’을 선택합니다.

  • 가입양식 입력

    에픽 게임즈에 이미 가입하신 고객님의 경우 팝업창 내에 계정정보를 입력하면 로그인이 가능합니다.
    계정 생성을 원하는 고객님께서는 ① 가입을 선택한 후 ② 이메일로 가입을 선택하시길 바랍니다.
    (※본 설명서는 '이메일로 가입' 이외의 가입 절차는 안내하지 않으니 양해 부탁 드립니다.)

  • 가입양식 입력 및 이용약관과 동의서 확인

    ③ 팝업창에 각각의 정보를 입력한 후 ‘이용약관에 동의하셔야 합니다’를 선택합니다.
    ④ 팝업창에 나타나는 규약을 모두 확인하지 않을 경우 다음 단계로 진행할 수 없습니다.
    특히 ‘이용 약관’은 모든 내용을 확인하지 않을 경우 하단의 ⑤‘동의합니다’ 버튼이 활성화되지 않으니 주의하시기 바랍니다.

  • 이용약관과 동의서 확인 완료

    각각의 체크 박스를 클릭한 후 ‘동의합니다’를 선택합니다. 이전 상태의 ⑦ 팝업창으로 돌아오게 되며, 정보 수신을 원하는 고객님께서는 체크 박스를 클릭한 후에 ‘계속’을 선택합니다. 정보 수신을 원하지 않는 고객님께서는 체크 박스 클릭 없이 ‘계속’을 선택합니다.

  • 인증용 보안 코드 입력

    ⑧ 팝업창을 통해 인증용 보안 코드를 입력해야 합니다. ③팝업창에서 고객님께서 입력한 이메일 주소에 에픽 게임즈로부터 ⑨인증용 보안 코드가 포함되어 있는 이메일이 도착하였는지 확인을 바랍니다.

  • 계정 생성 완료

    ⑩팝업창에 인증용 보안 코드를 입력하신 후 ‘이메일 인증’을 선택합니다. 이후 에픽 게임즈 메인 페이지로 화면이 자동 전환되며 이를 통해 에픽 게임즈 계정 생성은 끝이 납니다.
